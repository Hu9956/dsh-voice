# @kewen/dsh-voice · 语音交互

合并原「按住说话」和「语音朗读」：在插件详情里可分别启用按住说话、朗读与通话。关闭按住说话会恢复官方麦克风按钮；关闭朗读与通话会停止当前朗读并挂断电话。继续使用原有 `~/.config/dsh-voice/voice-reply.json`、百炼 Key 和浏览器朗读开关，无需迁移配置。不要同时启用两个旧插件，以免重复挂载或路由冲突。

按住说话：电脑在输入框文字区按住鼠标约 0.4 秒开始，松开结束；手机在输入框按住说话、轻点打字，上滑取消。识别结果插入草稿，不会自动发送。需要启用官方「语音输入」并准备模型。

主代理的回复边写边念。打开「语音模式」后，主代理写出第一句话，大约 1 秒后就开始念。合成用阿里云百炼的实时语音合成 `qwen3-tts-flash-realtime`，默认音色芊悦（Cherry）。

## 安装

1. 在 DSH 的「插件」页点击「添加插件」，输入 `https://github.com/Hu9956/dsh-voice` 并安装、启用。也可以从 [最新版本发布页](https://github.com/Hu9956/dsh-voice/releases/latest)下载安装包，在添加插件时输入安装包的本地路径。
2. 已安装的旧版「按住说话」和「语音朗读」请先停用，以免重复挂载。
3. 在「插件」→「语音交互」→「百炼 API Key」填写北京地域的百炼 API Key。要用按住说话或本机语音识别，还需启用官方「语音输入」并按提示准备 SenseVoice 模型。

百炼朗读和可选的云端语音识别按服务商价格计费，按住说话使用本机识别。详细说明见下方「准备」。

## 怎么用

- **语音模式**：点输入框左边的喇叭打开。主代理每一步写的话都念，调用工具之前说的中间回复也念。打开时已经写出来的内容不念，从接下来新写的一步开始；打开旧对话也不会把以前的回复重念一遍。
- **停止**：正在念时喇叭变成方块，点一下就停。这一轮剩下的不再念，下一轮照常。按住说话（dsh-voice-hold 0.3.1 起）也会马上停，免得麦克风录进朗读的声音。
- **单独朗读一条**：每条回复下面的操作栏里有小喇叭，点一下念这一条（最多 5000 字），再点一下停。不受「每轮最多念」的限制。
- **念之前先清理**：代码块换成「代码见屏幕」，表格换成「表格见屏幕」，链接只念文字，去掉标题、列表、加粗等符号。
- **主代理出错重试**：DSH 会把这一步重写一遍。已经念过的句子不再念，从说法变了的那句话开头接着念。

## 语音通话

电话按钮和 ChatGPT 一样放在发送按钮的位置：输入框空着、没附件、agent 没在跑、不在通话时，发送按钮显示成电话，点一下接通，像打电话一样和主代理说话。打了字或加了附件就变回发送箭头，agent 在跑时是停止按钮，通话中是官方发送按钮（挂断用胶囊上的红色按钮）。agent 在跑时打不了电话，要先等它做完或点停止。官方发送按钮没给插件留位置，这里按类名里的 `_primary` 认它；DSH 改了结构认不出来时，自动退回模型选择左边的小电话按钮。

- **通话胶囊**：接通后输入框正上方出现一个胶囊，输入框照常露着、能打字。左边是 Agent 头像（一团柔和的暖色光球，不转、没有硬边，靠呼吸和随音量的柔光表达状态，颜色随状态变：在听是奶桃色、在念是鼠尾草绿配奶黄、在想 / 在干活是淡紫配粉并呼吸得快一些、需要你确认偏琥珀、静音 / 暂停变灰；浅色主题各加深一点），中间是状态和提示，右边是静音、挂断，你正在说的时候多一个「说完了」。底部的波浪跟着声音动：你说话时跟麦克风，它念的时候跟朗读的音量（这时不看麦克风，免得回声把波浪带起来），在想 / 在干活时低幅度慢慢流动，静音、暂停时是一条平线。系统开了「减少动态效果」时只画静止的波浪。胶囊和输入框在同一层，输入区整体变高，不会盖住对话。胶囊的底色、磨砂、细边、投影和圆角照抄输入框卡片实际画出来的样子（读计算样式，不写死哪一套）：官方原版是实色，harness-plus 的单层 / 双层 / 待办栏玻璃、mobile-plus 的手机款都跟着走；换外观、换深浅色时自动重读。
- **一边打字一边说**：输入框里有你打的字（或附件）时，识别出来的话不自动发，接到草稿末尾，胶囊提示「已接到输入框末尾，发送时一起发」，你自己点发送。输入框空着时照旧自动发。这时识别为空（多半是键盘声）不提示；「停」「进度怎么样」照常当命令处理。
- **一轮怎么走**：接通响一声，胶囊显示「在听」。你说完停顿一下（默认 1.2 秒，可调），或者点「说完了」，就用本机的 SenseVoice 识别，识别出的话直接发出去，响一声表示收到。等回复时有很轻的思考音；它开口（比如「好，我先看一下日志」）思考音就停，开始朗读。它跑工具时显示「在干活」，每 15 秒轻响一下表示还在线。这一轮做完、念完，响一声，又轮到你说。
- **点一下胶囊**：停止朗读，马上轮到你说；agent 在后台照常干活，你说的话排队发出。
- **语音命令**：agent 在干活时说「停」「先停一下」「别做了」，会让它停下（和点「停止生成」一样）；说「进度怎么样」「做到哪了」「还要多久」，本地念一句进度（用了多久、走了几步、刚才在干什么），不发给 agent，也不打断它。agent 没在跑时，这些话照常发给它（比如它问你要不要继续，你说「停」）。
- **提问或审批**：agent 弹出提问、审批时，响一声并读「需要你在屏幕上确认」，处理完接着通话。
- **静音、挂断**：胶囊上的麦克风按钮静音，红色按钮挂断。草稿一直在输入框里，通话不会清掉或覆盖它。
- **没听清的不发**：识别为空、只有「嗯」「啊」这类语气词的不发，胶囊提示「没听清，请再说一遍」。

通话时后台会给模型加一段通话提示（口语化、先说结论、调工具前先说一句要做什么、删除和发送这类操作先口头确认、要选择时直接口头问）。提示在聊天里折叠成一行「上下文注入 · 语音通话开始」，挂断后再加一行「语音通话结束」，模型恢复正常写法。只加给打电话的那个会话，子代理不加。

需要先在插件页启用官方「语音输入」并下载好 SenseVoice 模型（和按住说话用的是同一个）。识别在本机，不花钱；朗读和语音模式一样按字计费。

### 通话设置

在「朗读设置」里：

- **通话停顿**：0.8 到 3 秒，默认 1.2 秒。你停顿这么久就当作说完。常被打断就调长一点。停顿中只响一下（敲键盘、碰桌子，不到 60 毫秒）不会让计时重来，要连续响一小段才算你又开口。
- **收音灵敏度**：很低、低、中、高，默认中。声音要比房间底噪高多少才算你在说话，门限有上下限，上限也跟档位走（底噪大时上限太低，门限会被压到离底噪只差几分贝，风扇声一波动就当成你还在说）：
  - 很低：高 24 分贝，门限 -38 到 -18 dBFS。给风扇、空调声很大的环境用，要说得响一点。
  - 低：高 18 分贝，-44 到 -24。
  - 中：高 12 分贝，-50 到 -28。
  - 高：高 8 分贝，-54 到 -28。
  环境吵、小杂音老让它以为你还在说、一直不发，就调低；说话轻、它听不到，就调高。低、很低两档在开着风扇的房间里实际用过，能正常断句；高档的数值是初值，没实测。
- **测一下环境噪声**：在设置页「环境噪声」一行点「测一下环境噪声」，实时显示现在的音量、底噪（最近 3 秒音量的第 20 百分位）、当前档位的门限，以及它认为你在不在说话；先安静 3 秒，会按底噪建议一个档位。最多测 60 秒。别在通话中测。
- **说话打断**：默认关。打开后，它念的时候你直接开口就能打断：一开口先把朗读声音压小，识别出是新的话就停下朗读、排队发出去；识别出的是朗读的回声（耳机漏音）就丢掉，朗读照常。外放时麦克风会录到朗读声，误打断多，所以只建议戴耳机时打开。
- **听语气断句**：默认关。打开后，你停顿 0.5 秒，就用本机的 smart-turn v3.2 模型听一下这句话的语气：像是说完了就马上发出去；像是还在想，就接着等，最多等 3 秒（「通话停顿」设得更长就按设置的）。每次判断约 0.3 秒，第一次约 0.6 秒（要启动），不联网、不花钱。模型和运行库随插件一起装（`vendor/`，来源和许可证见 `vendor/NOTICE.md`），判断出错时这通电话自动退回只按停顿判断，并提示一次。
- **锁屏后继续通话**：默认关，锁屏或切到别的 App 时通话暂停，回来点一下继续。打开后，锁屏、切后台时照常收音、发送、朗读。如果系统把麦克风或声音停了，通话会自动暂停，回来时胶囊显示「锁屏后系统停了麦克风或声音，点这里继续」。手机放进口袋时，摩擦声、旁边的人说话也可能被识别出来发给 agent，放口袋前最好先挂断或点静音。

### 测过什么

2026-11-05 在电脑上（DSH 桌面版，用自测录音代替麦克风，系统静音）测过：

- 连续 5 轮不碰键盘：说话 → 识别 → 自动发送 → 朗读 → 提示音 → 再听；后台通话提示只加了一次，模型每次调工具前先说一句。
- 听语气断句：3 轮都在停顿约 0.5 秒时判断为说完（概率 0.95、0.98、0.63），提前发出。
- agent 跑一个几分钟的命令时，点面板插话，说「进度怎么样」：没有发给 agent；说「先停一下」：agent 被停下（会话记录里这一轮以「用户中止」结束），这句话也没有发给 agent。

用户实测（2026-11-05）：电脑上用真麦克风通话；安卓上通话按钮可见、朗读音量正常、锁屏默认暂停，打开「锁屏后继续通话」后锁屏照常通话；打开「整段写完再念」后，用户判断已经生效（看开口时机，没有做服务端记录）；戴耳机打开「说话打断」后，打断朗读正常。还没测：iPhone 和其他浏览器。

### 开发自测

`~/.config/dsh-voice/call-test.json` 存在时：

- `clips: ["a.wav", …]`：通话不用麦克风，改为依次播放 `~/.config/dsh-voice/call-test/` 下的 16 位 PCM WAV（每段之间隔 `gapMs` 毫秒），用来在不出声的情况下测完整的通话循环。
- `debug: true`：每次 pre-step 的判断记到 `~/.config/dsh-voice/call-debug.log`。
- `force: ["会话 id"]`：这些会话不经浏览器也当作在通话（只给一次性的测试会话用）。

这些只读本机那个文件夹里的文件，接口也要先通过 DSH 的登录校验。平时不要留着这个文件：有 `clips` 时，任何会话里点电话按钮都会播放录音而不是开麦克风。

## 朗读设置

在侧栏「插件」里打开「语音交互」，详情页下面有「朗读设置」：

- **音色**：48 个，普通话 38 个，方言 10 个（上海话、北京话、四川话、粤语等）。旁边的「试听」用一段中英混合的话试念。
- **模型**：目前只有千问3 实时语音合成能用。2026-11-05 在北京地域逐个试过，百炼文档里其它实时语音合成的模型名都被拒；CosyVoice 等用的是另一套接口，本插件没接。
- **每轮最多念**：300、500、800（默认）、1500、3000 字或不限。念到上限就停，再说一句「后面的内容请看屏幕」。
- **整段写完再念**：默认关，主代理每写完一句就念一句。打开后，主代理每一步写完（或开始调工具）才把这一步的文字整段交给合成，整段一起合成，语调更连贯；代价是开口要等这一步写完。调工具前说的话写完就念，不用等整轮结束。语音模式和语音通话都按这个开关走；每条回复下面的小喇叭本来就是整段念。

改了立刻保存到 `~/.config/dsh-voice/voice-reply.json`，下一段朗读开始生效。设置存在运行 DSH 的电脑上，电脑和手机用的是同一份。

## 准备

1. 在阿里云百炼控制台（华北2 北京）创建 API Key。在 DSH 侧栏打开「插件」→「语音交互」→「百炼 API Key」，填写并保存百炼 API Key。已有 Key 显示为已配置，不会回显；要更换时填写新 Key 再保存。保存状态表示已填写，不代表百炼已验证或账户可用。朗读和可选的百炼语音识别共用此 Key。
2. Key 经当前页面提交到运行 DSH 的服务端，明文保存在服务端用户目录的 `~/.config/dsh-voice/dashscope.key`（文件权限 600），普通设置接口不会返回它。通过其他设备配置时请使用可信的加密连接。旧版手动放置的 Key 仍可继续使用；更换后下一次朗读或云端识别即生效。
3. 账户里要有余额。按字符计费：每万字符 1 元，一个汉字算 2 个字符。10 元大约能念 5 万个汉字，约 3 小时。调用失败（比如余额不足）时喇叭上会出现红点，鼠标停在上面能看到原因。

## 手机上

手机浏览器要用户点按过，网页才能出声。语音模式开着时，页面上的每次点按（按住说话、点发送、点输入框）都会顺手开启声音，一般不用专门去点喇叭。来电或切到后台之后，声音可能被系统停掉，这时喇叭会显示「轻点开启声音」，点一下就恢复。

## 已知限制

- 按 Esc 停不了朗读（Esc 是 DSH 停止主代理的快捷键），要停就点喇叭。
- iPhone 打开静音开关时，网页的声音可能也会被静音。
- 重试时说法变了，会从变了的那句话开头重念，可能和之前念过的半句重复。
- 一步最多念 2 万字，一段朗读最长 15 分钟。
- 语音通话：默认只看音量停顿判断「说完了」，停下来想事情时可能被截断（调长「通话停顿」、打开「听语气断句」，或用「说完了」）。外放时默认不能用说话打断，要点胶囊。锁屏、切到后台默认暂停，回来点一下继续；打开「锁屏后继续通话」后能不能接着录音取决于手机系统和浏览器，系统停了麦克风就自动暂停。用户的安卓手机上锁屏后能继续通话（2026-11-05）；其他手机和浏览器（尤其 iPhone）没测过。
- 语音通话默认用人声模型（Silero VAD，本机运行）过滤风扇、空调、键盘这类非人声；但电视、旁人说话也是人声，照样会被当成你说的，胶囊上会显示识别出的话。第一次通话要下载约 6 MB 的运行库和模型，之后走浏览器缓存。
- 插件包约 12 MB，大部分是 smart-turn 的模型（8.7 MB）和 ONNX 运行库（14 MB，未压缩）。
