# @kewen/dsh-voice · 语音交互

为 DSH 提供完整的语音交互体验，包含 **按住说话**、**回复朗读** 与 **语音通话** 三项能力。在插件详情页中，「语音输入」与「朗读与通话」可分别独立开关。

- **按住说话**：无需去点角落的麦克风图标——在输入框直接按住就能说话，松开后识别文字并写入草稿。
- **回复朗读**：主代理边写边念，首句写出约 1 秒即开口；也支持单条回复按需点播。代码块、表格和 Markdown 符号会自动转换为口语提示。
- **语音通话**：像打电话一样与主代理连续对话。内置本地人声检测（Silero VAD）与语气断句模型（smart-turn），支持中途插话、语音口令（「停」「进度怎么样」）以及边打字边说。

---

## 安装与准备

### 1. 安装插件

在 DSH 侧栏打开「插件」→「添加插件」，输入仓库地址安装并启用：

```text
https://github.com/Hu9956/dsh-voice
```

也可以从 [Releases](https://github.com/Hu9956/dsh-voice/releases/latest) 下载最新的 `.tgz` 安装包，在「添加插件」时填入本地文件路径。

> 如之前安装过单独的「按住说话（`dsh-voice-hold`）」或「语音朗读（`dsh-voice-reply`）」，请先将它们停用或卸载，避免重复挂载。原有的 `~/.config/dsh-voice/` 配置与 API Key 会自动沿用。

### 2. 准备语音识别与语音合成

| 功能 | 所需准备 | 费用与运行方式 |
| --- | --- | --- |
| **按住说话 / 通话默认识别** | 在 DSH「插件」页启用官方 **「语音输入」**，并在其详情页下载好 SenseVoice 模型 | 本机运行，免费 |
| **回复朗读 / 语音通话合成** | 在「插件」→「语音交互」→ **「百炼 API Key」** 中填写阿里云百炼（**华北2·北京**）API Key | 走百炼 `qwen3-tts-flash-realtime`，每万字符 1 元（1 个汉字算 2 字符，10 元约合 5 万汉字 / 3 小时） |
| **通话云端识别（可选）** | 同上（共用百炼 API Key），在设置中开启「百炼识别」 | 走百炼 `qwen3-asr-flash`，按服务商价格计费；识别失败自动回退本机 |

> **关于 API Key 存储**：在插件设置页提交的 Key 会保存在运行 DSH 的服务端 `~/.config/dsh-voice/dashscope.key`（权限 `600`），普通设置接口不会回传明文。跨设备访问 DSH 时请使用可信的加密连接。

## 功能与用法

### 一、按住说话

去掉了发送键旁单独的麦克风按钮，改为直接在输入框操作：

- **电脑端**：在输入框文字区按住鼠标左键约 0.4 秒开始录音，松开结束。按住拖动（选字）不会触发录音；录音中移动鼠标或按 `Esc` 取消。
- **手机端**：键盘未弹出时，按住输入框说话、松手结束、上滑取消；轻点输入框弹出键盘打字。键盘弹出后，长按恢复为系统选字与粘贴。
- **只进草稿、不自动发**：识别结果追加到输入框草稿末尾，由你确认后发送。若正在录音时开始朗读，录音会自动停止，避免把朗读声录进去。

### 二、回复朗读

- **语音模式（自动跟读）**：点击输入框左侧的喇叭图标开启。开启后主代理接下来新写出的每一句话都会边写边念（包括调用工具前的过渡说明），已写出的历史内容不会重念。
- **单条点播**：每条回复底部的操作栏都有小喇叭按钮，点击即可朗读该条回复（最长 5000 字），不受「每轮最多念」字数限制。
- **随时停止**：正在朗读时喇叭变为停止方块，点一下即停，本轮剩余内容不再念，下一轮恢复正常。
- **口语化清理**：朗读前会自动把代码块替换为「代码见屏幕」、表格替换为「表格见屏幕」，链接只念文字，并去掉标题、列表、加粗等格式符号。
- **重试续念**：主代理出错重试时，已经念过的句子不会重念，只从说法发生变化的那句话接着念。

### 三、语音通话

当输入框为空、无附件且主代理未在运行时，右下角发送按钮会显示为**电话图标**，点击即可接通。

- **通话胶囊**：接通后在输入框正上方展开通话胶囊（不遮挡对话，输入框仍可正常打字）。左侧光球随状态呼吸变色，底部声浪随你或主代理的声音起伏；右侧提供**「说完了」**（说话时出现）、**倍速切换**、**静音**与**挂断**按钮。
- **自然轮流对话**：
  1. 接通后提示音一响即可开口，说完停顿片刻（默认 1.2 秒）或点「说完了」自动发送；
  2. 等待回复时播放轻柔思考音，主代理一开口即转为朗读；运行工具时显示「在干活」，每 15 秒轻响一次表示在线；
  3. 本轮念完后提示音再响，自动轮到你接着说。
- **一边打字一边说**：如果输入框里已经有草稿文字或附件，通话中识别出的话**不会自动发送**，而是追加到草稿末尾，等你手动点发送。
- **随时插话与打断**：主代理在朗读或干活时，点一下胶囊即可停下朗读直接开口；戴耳机时也可在设置中开启「说话打断」，直接开口打断。
- **本地语音口令**：主代理运行工具时，直接说 **「停」「先停一下」「别做了」** 会立即中止当前生成；说 **「进度怎么样」「做到哪了」「还要多久」** 会在本地播报当前耗时、步数和刚执行的动作，不打断主代理、也不消耗模型上下文。
- **提问与审批提醒**：遇到需要人工确认的提问或工具审批时，会响声并播报「需要你在屏幕上确认」，处理完后自动继续通话。
- **口语化提示注入**：通话期间后台会为当前会话注入简洁的口语化指令（先说结论、调工具前先打招呼、高风险操作先口头确认），挂断后自动恢复正常书面回复，不影响子代理。

## 插件设置

在侧栏「插件」→「语音交互」详情页中，所有修改立即保存到服务端 `~/.config/dsh-voice/voice-reply.json`（电脑与手机端共用同一份配置）：

### 语音输入与总开关

- **按住说话**：开启或关闭输入框按住说话；关闭后恢复官方麦克风按钮。
- **百炼 API Key**：填写或替换北京地域的百炼 API Key。
- **启用朗读与通话**：一键开关朗读与语音通话功能，关闭时停止当前朗读并挂断通话，不影响按住说话。

### 朗读

- **音色**：内置千问3 实时语音合成（`qwen3-tts-flash-realtime`）的 **48 种音色**（38 种普通话 + 10 种方言，含沪语、京味、川话、粤语、闽南语、陕西话、天津话等），默认「芊悦（Cherry）」，支持一键试听。
- **语速**：`1×`、`1.25×`、`1.5×`、`2×`（变速不变调，从下一段朗读起生效；通话胶囊上也可直接点击切换）。
- **每轮最多念**：`300`、`500`、`800`（默认）、`1500`、`3000` 字或 `不限`。超出后播报「后面的内容请看屏幕」。
- **整段写完再念**：默认关闭（逐句边写边念，延迟最低）。开启后等主代理写完一整步再合成，语调更连贯，但开口等待更久。

### 通话与收音

- **百炼识别**（云端，默认关）：开启后通话录音使用百炼 `qwen3-asr-flash` 云端识别，准确率高于本机 SenseVoice；异常时自动回退本机识别。
- **通话停顿**：`0.8`–`3.0` 秒（默认 `1.2` 秒），停顿达到该时长即视为说完。偶发的键盘敲击或碰桌声（< 60 ms）不会重置计时。
- **听语气断句**（本机，默认关）：停顿 0.5 秒后用本机 `smart-turn v3.2` 模型判断话有没有说完——说完了立即发出，像在思考则继续等待（最长 3 秒），不联网、不计费。
- **说话打断**（默认关）：开启后可在主代理朗读时直接开口打断（建议仅在**戴耳机**时开启，外放容易录进回声造成误打断）。
- **锁屏后继续**（默认关）：默认锁屏或切后台时暂停通话；开启后保持后台收音与朗读（手机放口袋前建议先静音或挂断，防误触录音）。
- **收音设置（折叠项）**：
  - **只听人声**（本机，默认开）：使用本机 Silero VAD 过滤风扇、空调、键盘等非人声噪音。
  - **收音灵敏度**：`很低`、`低`、`中`（默认）、`高` 四档，并附带 **「环境噪声」实时检测仪**，先安静 3 秒即可根据房间底噪给出档位建议。

## 移动端与注意事项

- **手机浏览器自动出声**：移动端网页需有用户点按才能播放声音。开启语音模式后，页面上的日常点按（点输入框、按住说话、点发送）都会自动激活音频；若来电或切后台导致声音被系统挂起，喇叭旁会提示「轻点开启声音」，点一下即可恢复。
- **iPhone 静音开关**：iPhone 拨下机身静音键时，网页朗读可能随系统静音。
- **人声过滤边界**：本地 VAD 能过滤风扇、键盘等环境噪声，但电视声或旁人说话同样属于人声，仍可能被识别；仅说「嗯」「啊」等语气词或未听清时不会发送。
- **体积与首次缓存**：插件包约 12 MB（主要为内置的 `smart-turn` 模型与 ONNX 运行库）；首次开启语音通话时浏览器会从本地服务端加载约 6 MB 的 VAD 模型并缓存。
